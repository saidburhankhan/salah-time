## R5 app fixes

### Backend request for routine activity

The app needs `routines.activity` with params `{from, to, limit?, before?}`. The inclusive range uses tracking days in `YYYY-MM-DD` format and spans at most 14 days. Return `{rows: [{item_id, day, minutes, done}], next: string | null}`, with one row per live recurring task and day that has activity, ordered by day descending and item ID ascending. Sum the finished duration sessions into integer `minutes`. A finished completion tick sets `done: true`. Exclude running and removed sessions, nonrecurring tasks, and work without a task. Use an opaque continuation cursor and cap each page at 500 grouped rows. For CLI fallback, the equivalent requested command is `salah routines activity --from DATE --to DATE --limit 500 [--before CURSOR] --json`. The current fallback requests 12 full sessions per page and follows the existing cursor. One session with enough notes can still exceed the transport limit until the projection is available.
