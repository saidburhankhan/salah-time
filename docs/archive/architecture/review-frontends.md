# Front-end architecture review

Scope: `app/` and `plugin/local.salah/` on `items-mvp`. Severity means **critical** (data loss/corruption), **high** (likely incorrect behavior or blocks safe growth), **medium** (material maintainability/testability risk), or **low** (localized quality gap). No critical issue was confirmed from static review.

## Architectural diagnosis

The queues and in-place list updates are useful MVP work, but they sit at the wrong layer. Both UIs are simultaneously transport adapters, domain interpreters, optimistic databases, formatters, and views. Adding Telegram, Slack, notes, or another desktop surface would copy those rules again. The durable seam is an authoritative Rust application API with versioned DTOs, revision-aware commands, and projections designed for each view; front ends should own interaction state and rendering only.
